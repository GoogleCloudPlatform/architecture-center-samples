Queries agency-configured procurement approval limits and expense-type receipt rules from EBS setups. Pass an operating unit ID in org_id (empty string = all) and a name fragment in rule_name (empty string = all); pass as_of_date (YYYY-MM-DD) for the rules in force on a date (empty = all rules, active or not); at most 200 rows are returned. These tables have no start date: created_date is when the rule was set up, and effective_end_date is when it was ended or inactivated. In the EXPENSE category, threshold_amount is the amount above which a receipt is required (see threshold_meaning); it is not a spending cap. Per diem and lodging limits live in the expense policy schedules, which this tool does not read.
Underlying Tables: PO_CONTROL_RULES, PO_CONTROL_GROUPS_ALL, AP_EXPENSE_REPORT_PARAMS_ALL.
Security Context: Standard APPS schema access; Global profile options context.
