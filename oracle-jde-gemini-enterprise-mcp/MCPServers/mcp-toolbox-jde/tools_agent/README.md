# jde/tools_agent/

Generated by `scripts/build_and_validate.py`. Do not edit; it is git-ignored and rewritten on every build.

**Who is the user?** The calling agent says so. `user_id` is a plain required parameter, and the agent fills it
with the e-mail it has already verified.

- Every tool is wrapped in the PL/SQL security block, so the database applies that user's access rules.
- The Toolbox does **not** check who is calling (no `authServices`, no `authRequired`).
- Deploy it only behind a private service that nobody but the agent can invoke, because anyone who can call
  the Toolbox can claim to be any user.
- Deploy: `scripts/deploy_mcp_server.sh --system jde --variant agent`
